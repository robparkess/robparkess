# About Me:
I’m Rob, a sports data analyst focused on building end to end analytics workflows that turn raw data into practical decision making tools.

I recently completed my MSc in Data Analytics in Sport at TU Dublin, where my work centres on football event data, pipeline design, and applied performance analysis.

My thesis project was a five-dashboard Tableau tool built with the Irish Football Association to help their coaching staff prepare for a competitive campaign. A redacted version is pinned below: [thesis-ifa-tactical-dashboard-suite](https://github.com/robparkess/thesis-ifa-tactical-dashboard-suite).

I work as Head of Data Analytics at Blue Martini Group, leading reporting, performance tracking, and dashboard development across multiple UK and Irish venues.
